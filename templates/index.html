✨ Metode Utama - Mendukung Verifikasi 2FA
🛡️ Tips Anti-Block:

Jika akun Anda meminta verifikasi 2FA atau kode OTP, halaman input kode verifikasi akan muncul otomatis setelah Anda menekan tombol Login.

⚡ Solusi Tercepat Jika IP VPS Terblokir

💡 Cara Ambil SessionID dari Browser:

  1. Buka instagram.com di browser yang sudah login akun Anda
  2. Tekan F12 (Developer Tools)
  3. Buka tab Application (Chrome/Edge) atau Storage (Firefox)
  4. Klik Cookies → https://www.instagram.com
  5. Cari nama sessionid dan copy nilainya (Value)
  6. Paste di atas dan klik Login. Tidak perlu password!
📁 Cadangan - Import File JSON

📖 Cara Mendapatkan Session JSON:

Gunakan script pembantu python get_session.py dari komputer lokal jika server VPS mengalami pembatasan IP oleh Instagram.

Catatan Keamanan:

Kredensial Anda hanya disimpan secara lokal di sesi server VPS Anda sendiri untuk mengakses data pengikut Instagram secara aman.
