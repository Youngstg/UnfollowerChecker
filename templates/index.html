⚠️ Jika login gagal (IP blocked):

Gunakan tab "Import Session" sebagai gantinya. Lebih aman dan tidak kena block.

📖 Cara Mendapatkan Session JSON:

  1. Install Python package: pip install instagrapi
  2. Buat file get_session.py dengan kode: 
    from instagrapi import Client

cl = Client()
cl.login("username_kamu", "password_kamu")
cl.dump_settings("session.json")

# Baca dan print
import json
with open("session.json") as f:
    print(json.dumps(json.load(f), indent=2))
  3. Jalankan: python get_session.py
  4. Copy output JSON dan paste di atas

Atau lebih mudah: Login dengan password dulu dari komputer/IP yang tidak di-block, lalu session akan otomatis tersimpan untuk penggunaan berikutnya.

Catatan Keamanan:

Login credentials disimpan dengan aman dan hanya digunakan untuk mengakses data Instagram Anda. Kami tidak menyimpan password Anda.
